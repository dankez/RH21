# XTB ETF Portfolio Copilot

An AI assistant for Slovak retail investors to analyze ETF, stocks, and portfolios in XTB.

## Project Overview
This project provides a professional, regulatory-compliant AI copilot designed to help retail investors navigate their investment journey on the XTB platform. It focuses on transparency, risk assessment, and localized Slovak content.

## Features
- **Onboarding Questionnaire**: Multi-step form to assess risk profile, horizon, and goals.
- **Portfolio Dashboard**: Comprehensive overview with P/L, asset allocation, and risk scores.
- **AI Copilot Chat**: Conversational interface for portfolio analysis and rebalancing suggestions.
- **Data Import**: Easy CSV/XLSX export upload from XTB.

## Legal Disclaimer
This application does not provide licensed investment advice. All suggestions are for educational and analytical purposes only. Users are responsible for their own investment decisions.
