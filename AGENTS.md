# Agent Instructions for XTB ETF Portfolio Copilot

## Core Mission
This project is an AI-powered portfolio assistant for Slovak retail investors. It focuses on analyzing ETFs and stocks from the XTB platform.

## Design Principles
- Use the 'Institutional Trust' design system from Stitch (assets/45372bfe07284f5caaa077b85850f485).
- Always include the legal disclaimer: "Nie je to licencované investičné poradenstvo."
- All user-facing text should be in Slovak.

## Regulatory Compliance (MiFID II)
- Never perform trades without explicit user confirmation.
- Always ask for risk profile, horizon, and suitability before giving specific suggestions.
- Differentiate between educational model portfolios and personalized advice.

## Technical Details
- Frontend: Next.js with Tailwind CSS.
- Design: Managed via Stitch (Project ID: 13382153530622202862).
